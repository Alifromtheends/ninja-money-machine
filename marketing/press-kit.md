## The Story

Ninja Money Machine is an experiment in **agent-assisted solo development**. Rather than coding every line personally, the builder orchestrated multiple specialized AI agents — frontend, backend, copy, testing — to work in parallel. The result: 4 functional products in a single 4-hour sprint.

The thesis: one human with good taste and solid architecture skills can now ship at the speed of a small studio by delegating implementation to AI agents.

All products are live, functional, and open source.

---

## The Products

### 1. Markup — Privacy-First Markdown Editor
A markdown editor with 7 themes, cloud sync, Stripe billing, and a Chrome extension. Built for users who want their notes to stay private and portable.

🔗 https://alifromtheends.github.io/markuptool/

### 2. TL;DR — On-Device Webpage Summarizer
A Chrome extension that summarizes any webpage into 3 bullets using client-side NLP (Transformers.js). Works 100% offline with zero server dependencies.

🔗 https://seed-dev-tool-1779205224843.vercel.app

### 3. PostPilot — Social Media Scheduler
A scheduling tool with AI hashtag generation, calendar view, and analytics. Schedule once, post everywhere.

🔗 https://seed-ai-automation-1779205224828.vercel.app

### 4. NoteNinja — AI Meeting Notes
A meeting notes tool with real speech-to-text and automatic action item extraction. Record, talk, receive structured notes.

🔗 https://seed-productivity-1779205224843.vercel.app
