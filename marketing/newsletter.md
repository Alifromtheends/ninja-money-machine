## Behind the Build

Here's what surprised me most about working with agent swarms:

**1. Parallelization is real.** While one agent built the React frontend, another scaffolded the API, and a third wrote landing page copy. I was the coordinator, not the sole builder.

**2. Agents know patterns.** Stripe integrations, Chrome extensions, CSS theming — they've seen it all. The code they produce is often more idiomatic than what I'd write from scratch.

**3. Humans still matter.** For architecture decisions, taste calls, and edge case debugging, there's no substitute for human judgment. Agents multiply your speed; they don't replace your brain.

**4. Context is everything.** The biggest challenge wasn't prompting — it was managing what context each agent received. Too little, and they build the wrong thing. Too much, and they get confused.
