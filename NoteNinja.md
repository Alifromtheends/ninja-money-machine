- Voice-to-text transcription with animated waveform
- AI extracts action items, assignees, and deadlines
- Interactive checklists for task management
- Smart summary generation
- Export to Markdown, JSON, or clipboard
- localStorage persistence

- HTML, CSS, JavaScript

## How to Use
1. Visit: https://seed-productivity-1779205224843.vercel.app/app.html
2. Click "New Meeting" to start
3. Paste a transcript or type notes
4. AI auto-extracts:
   - Action items
   - Who's responsible
   - Deadlines
5. Export as Markdown, JSON, or copy to clipboard

## Key Features
- **Voice Recording**: Animated waveform visualization (simulated demo mode)
- **AI Extraction**: Automatically finds tasks, owners, and due dates
- **Smart Summary**: One-paragraph meeting recap
- **Action Checklist**: Interactive todos with checkboxes
- **Export Options**: Markdown, JSON, or plain text
